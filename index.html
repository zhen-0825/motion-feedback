🍎 老師快速上手

  1. 到「🧒 身體資料與設定」輸入學員身高、體重。
  2. 在「📷 即時鏡子」按 開啟鏡頭，第一次使用要允許相機權限。
  3. 讓學員全身入鏡。要看側面動作（例如蹲、跳、跑）時，鏡頭要擺在側邊，盡量與動作平面垂直、和腰部同高。
  4. 按 🔴 錄影，會倒數 3 秒後開始錄影。錄好的影片可以在「📊 錄影回顧」慢動作、逐格播放，並對照角度曲線。
  5. 在「🎬 跟著影片練」放入示範影片或存一個目標姿勢，學員跟著做，系統就會給星星和提示。
所有影像都只在這台裝置上即時分析，不會上傳。第一次開啟需要網路來下載 AI 模型（約 5–30 MB），之後瀏覽器通常會快取。
手機和平板上的瀏覽器只有在 https 網址下才能開啟相機。用電腦直接點開這個檔案就可以；如果要在手機或平板上使用，請把這個檔案放到 GitHub Pages、Netlify Drop 等網站，再用網址開啟。

🦴 33 個身體標記點與對應骨性標記

BlazePose 的點是 AI 從影像推估的「關節中心附近位置」，不是真的貼在骨凸上的反光球，所以會比 Vicon 等標記點系統有更多誤差。

🧮 計算方法

  • 關節角度：用三個點組成的兩個向量求夾角，θ = arccos( (u·v) / (|u||v|) )。例如膝角是「髖－膝－踝」三點的夾角。
  • 軀幹前傾：兩髖中點指向兩肩中點的向量，與鉛垂線的夾角。
  • 全身重心：各肢段重心 = 近端點 + 比例 ×（遠端點 − 近端點），全身重心 = Σ(肢段質量比 × 肢段重心)。
  • 像素換算公尺：用大腿、小腿、軀幹的像素長度，對照 Drillis & Contini 的身高比例（大腿 0.245H、小腿 0.246H、軀幹 0.288H），取中位數。
  • 速度、加速度：重心位置經平滑後做數值微分。
  • 估計垂直地面反作用力：F = m(g + a垂直)，以「幾倍體重（BW）」顯示。這是由影像推估的數值，雜訊比測力板大很多。
